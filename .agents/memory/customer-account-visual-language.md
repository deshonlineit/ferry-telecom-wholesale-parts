---
name: Customer account visual language
description: Defines the owner-approved visual direction for customer profile, address, order, and return screens.
---

Customer account screens must feel like a purpose-built B2B repair-shop
workspace, not a generic CMS or WordPress settings page.

**Why:** the owner rejected the detached sidebar, oversized empty form surface,
weak hierarchy, and grey primary action as looking like a low-quality
WordPress account page.

**How to apply:** keep account navigation and content visually continuous,
give profile and operational data clear hierarchy, distinguish locked data from
editable fields, use confident primary actions, and maintain the same system
across profile, addresses, orders, and returns on desktop and mobile.
