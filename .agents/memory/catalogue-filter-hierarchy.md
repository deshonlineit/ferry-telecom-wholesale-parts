---
name: Catalogue filter hierarchy
description: Visual and semantic hierarchy for the buyer catalogue’s filter sidebar and dialog.
---

The primary catalogue-filter flow is model, part category, then part subtype
when applicable. Product/device brand, quality, and stock belong under the
secondary “more filters” section. Selected primary values should read as one
calm guided flow, not as unrelated form boxes.

**Why:** Giving brand equal visual weight before model and part made the rail
feel chaotic and obscured the buyer’s actual task. Long selected values and
model searches also need enough width or a two-line treatment to remain
recognizable.

**How to apply:** preserve this order in both the desktop rail and mobile
filter dialog. Keep selected states subtle but visible, open secondary filters
when one of their values is active, and verify long model/category names at
real sidebar widths.
